# @goatlint/types

TypeScript definitions for the Oxc AST.

This package provides type definitions for the AST nodes produced by Oxc's JavaScript/TypeScript parser.

## Installation

```sh
npm install -D @goatlint/types
```

## Usage

```typescript
import type { Program, Statement, Expression } from "@goatlint/types";
```
